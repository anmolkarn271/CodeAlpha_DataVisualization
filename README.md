# CodeAlpha Data Visualization

## Internship Domain
Data Analytics

## Task Description
This project is part of the CodeAlpha Data Analytics Internship.
The objective of this task is to transform raw data into meaningful visualizations
that help in understanding patterns and insights.

## Dataset
The dataset contains information about books scraped from books.toscrape.com.
It includes book title, price, availability, rating, and product link.

## Project Structure
- code/ : Python script for data visualization
- data/ : Dataset used for visualization
- output/ : Screenshots of generated visualizations

## Tools Used
- Python
- Pandas
- Matplotlib

## Visualizations Created
- Bar chart showing number of books by rating
- Bar chart showing average book price by rating
- Histogram showing price distribution of books

## Insights
- Some ratings contain more books than others
- Book prices vary across different ratings
- Most book prices fall within a specific range
